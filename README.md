## Projects

### 01. Number Swapping

**File:** `Course1.py`

**Description:**

A simple Python program that takes two integer numbers from the user and swaps their values.

**Concepts Covered:**
- Variables
- User input (`input()`)
- Integer conversion (`int()`)
- Print statements
- Multiple assignment

**Example:**

```text
First number: 5
Second number: 10

After swapping:
First number: 10
Second number: 5
```
